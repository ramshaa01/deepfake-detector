# Dataset Card: Deepfake Detector Balanced Subset

## Overview
This dataset is a custom 2,000-image balanced subset created specifically for training and evaluating the AI-Generated Face Detector. It pairs real human photographs with synthetic faces generated by a specific GAN architecture to isolate deepfake upsampling artifacts.

## Dataset Composition
The dataset consists of 2,000 face images (1024×1024 raw resolution, cropped to 224×224 for training).

| Split | Real (FFHQ) | Fake (StyleGAN2) | Total |
|---|---|---|---|
| **Train** | 700 | 700 | 1,400 |
| **Validation** | 150 | 150 | 300 |
| **Test** | 150 | 150 | 300 |
| **Total** | 1,000 | 1,000 | 2,000 |

### 1. Real Images: FFHQ (Flickr-Faces-HQ)
- **Source:** [NVlabs/ffhq-dataset](https://github.com/NVlabs/ffhq-dataset)
- **Description:** A high-quality image dataset of human faces, originally created as a benchmark for generative adversarial networks (GANs). It contains considerable variation in terms of age, ethnicity, and image background.
- **License:** Creative Commons BY-NC-SA 4.0. The dataset is intended for non-commercial research purposes.

### 2. Fake Images: "1 Million Fake Faces" (StyleGAN2)
- **Source:** Generated using the NVIDIA StyleGAN2 architecture (often sourced via "1 Million Fake Faces" repositories or generated directly using the FFHQ-trained StyleGAN2 weights).
- **Description:** Entirely synthetic faces generated by a neural network. 
- **License:** Inherits non-commercial licensing constraints (e.g., CC BY-NC 4.0 or similar) from the underlying FFHQ dataset it was trained on and the StyleGAN2 source code.

## Known Distributional Characteristics and Biases

Through rigorous model evaluation (Days 20 and 36), several critical distributional characteristics of this dataset were identified:

### 1. Eyeglasses Distribution Skew (Spurious Shortcut)
There is a pronounced distributional mismatch regarding eyeglasses. Real images from FFHQ contain a natural diversity of individuals wearing eyeglasses. However, StyleGAN2 struggles to perfectly synthesize symmetric eyeglass frames. Consequently, the dataset contains significantly more "clean" eyeglasses in the Real class. Models trained on this dataset tend to learn eyeglasses as a spurious proxy for the "Real" class, causing elevated false-positive (predicted "Fake") rates on real people wearing glasses.

### 2. Single-Generator Scope
The "Fake" class is exclusively composed of StyleGAN2-generated images. These images contain specific high-frequency spectral artifacts (grid patterns resulting from transposed convolutions). Models trained on this dataset overfit to these specific artifacts and fail to generalize to other generative architectures (e.g., StyleGAN3, which uses an alias-free design and suppresses these artifacts). 

## Data Pipeline
- **Face Extraction:** The raw 1024x1024 images were processed using MTCNN to extract tight bounding boxes around the face.
- **Preprocessing:** Cropped to 224x224 pixels and normalized using standard ImageNet mean and standard deviation before being fed to the model.
- **Splits:** Generated using a fixed random seed (`random.seed(42)`) with strict stratification to prevent cross-split contamination.
